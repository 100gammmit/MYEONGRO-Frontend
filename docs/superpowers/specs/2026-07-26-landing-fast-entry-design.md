# 빠른 리딩 진입형 랜딩 디자인

## 배경

현재 랜딩은 Celestial Dark의 딥 퍼플·라일락 색상과 Lunar Editorial의 분위기를 잘 전달하지만, 데스크톱과 모바일 모두 장식적인 히어로가 길어 핵심 사용자 행동인 타로·사주 선택이 늦게 나타난다.

이번 변경은 기존 브랜드와 페이지 구조를 크게 바꾸지 않으면서 첫 방문자가 서비스의 성격을 이해하고 두 리딩 중 하나를 빠르게 선택하도록 만드는 데 목적이 있다.

## 목표

- 데스크톱 첫 화면에서 히어로 CTA와 타로·사주 선택 영역의 시작을 함께 인지할 수 있게 한다.
- 모바일에서도 장식보다 제목, 설명, CTA, 선택 카드가 먼저 보이게 한다.
- 기존 Celestial Dark 색상, 별빛 배경, 세리프 중심의 Lunar Editorial 인상을 유지한다.
- 기존 로그인 및 타로·사주 사용자 흐름과 URL을 그대로 유지한다.
- 향후 광고 도입 시 랜딩 구조를 다시 뜯어고치지 않아도 되도록 콘텐츠 구간 사이에 자연스러운 삽입 여지를 남긴다.

## 비목표

- 광고 스크립트, 광고 슬롯 또는 빈 광고 플레이스홀더를 추가하지 않는다.
- 로그인, 타로, 사주, 리딩 기록 등 다른 페이지를 재설계하지 않는다.
- 인증, 리딩 생성, 기록 저장 등 기능 로직을 변경하지 않는다.
- 공개 콘텐츠 허브나 블로그 기능을 추가하지 않는다.
- 전역 브랜드 팔레트나 전역 타이포그래피를 다시 정의하지 않는다.

## 선택한 방향

비교안 중 **A. 빠른 리딩 진입**을 사용한다. 사용자의 추가 피드백에 따라 히어로의 행성·달·궤도 심볼은 모두 제거하고, 기존 왼쪽 카피와 CTA를 단일 중앙 열로 모은다.

시각적 신비감은 대형 천체 일러스트가 아니라 다음 요소로 유지한다.

- 기존 별빛 및 퍼플 글로우 배경
- 골드 계열 영문 키커
- 라일락 CTA와 얇은 반투명 테두리
- 여백이 넓은 중앙 정렬 타이포그래피
- 선택 카드의 미세한 원형 선과 광택 효과

## 국내 서비스 참고 원칙

국내 감성형 콘텐츠 서비스인 롱블랙의 짧고 강한 한국어 제목, 넓은 여백, 단계별 정보 전개와 운세 서비스 포스텔러의 빠른 카테고리 진입 방식을 참고한다. 특정 화면이나 자산을 복제하지 않고 다음 원칙만 명로의 디자인 언어로 번역한다.

- 첫 화면의 문장을 짧게 유지한다.
- 서비스 설명보다 사용자가 바로 고를 수 있는 선택지를 먼저 보여준다.
- 큰 한국어 제목과 작은 기능 설명의 대비를 분명히 한다.
- 장식 수를 늘리기보다 여백, 글꼴, 얇은 구분선으로 감성을 만든다.
- CTA 문구는 추상적인 표현보다 다음 행동이 드러나는 동사를 사용한다.

- 포스텔러: <https://forceteller.com/>
- 네이버 마루 프로젝트: <https://hangeul.naver.com/maruproject_11>

## 타이포그래피

### 글꼴 조합

- 한국어 제목 및 카드 제목: **마루부리**
- 본문, 설명, 버튼, 내비게이션 및 메타 정보: **Pretendard**
- 영문 브랜드 워드마크와 짧은 영문 키커: 현재 로만 세리프 계열을 유지하되 한국어 제목과 충돌하지 않게 사용한다.

마루부리는 화면용 부리체로 설계되어 한국어 제목에 편집물 같은 인상을 주면서도 본문용 글꼴의 가독성을 갖는다. Pretendard는 작은 크기의 한국어와 숫자, 영문이 섞인 UI에서 균형이 좋아 기능 문구에 사용한다.

### 적용 범위

- 이번 단계에서는 랜딩 콘텐츠에만 새 글꼴 조합을 적용한다.
- 다른 페이지의 실제 렌더링은 변경하지 않는다.
- 랜딩 내부의 `h1`, `h2`, 카드 `h3`는 마루부리를 사용한다.
- 랜딩 본문, CTA, 키커, 단계 설명은 Pretendard를 사용한다.
- 공통 헤더와 푸터는 기존 글꼴 규칙을 유지한다.

### 굵기와 자간

- 히어로 `h1`: 마루부리 Regular 400, 데스크톱 56~68px 범위, 모바일 36~44px 범위
- 섹션 `h2`: 마루부리 Regular 400
- 카드 `h3`: 마루부리 Regular 또는 SemiBold 400~600
- 본문: Pretendard Regular 400
- 버튼 및 짧은 UI 라벨: Pretendard Medium 또는 SemiBold 500~600
- 한국어 제목의 자간은 약 `-0.04em`에서 시작하되 글자가 뭉치지 않도록 실제 화면에서 조정한다.
- 본문 자간은 전역의 과도한 음수 값을 그대로 상속하지 않고 `-0.01em` 안팎으로 완화한다.
- 본문 줄 높이는 최소 1.6, 큰 제목 줄 높이는 1.12~1.2를 기준으로 한다.

### 로딩과 성능

- CSS에 글꼴 이름만 선언하고 사용자 기기의 설치 여부에 맡기지 않는다.
- 공식 배포본을 프로젝트에서 자체 호스팅하며 외부 CDN 런타임 요청을 만들지 않는다.
- 사용하지 않는 굵기는 포함하지 않는다. 마루부리는 400과 필요한 경우 600, Pretendard는 400·500·600만 우선한다.
- `font-display: swap`을 사용하고 적절한 시스템 폰트 fallback을 둔다.
- 글꼴 라이선스 파일과 출처를 함께 보존한다.
- 글꼴 적용 후 레이아웃 이동과 모바일 줄바꿈을 별도로 확인한다.

## 정보 구조

위에서 아래로 다음 순서를 사용한다.

1. 기존 사이트 헤더
2. 중앙 정렬 히어로
3. 타로·사주 선택 카드
4. 짧은 신뢰 정보 스트립
5. 3단계 이용 방법
6. 기존 사이트 푸터

새로운 장문 섹션은 추가하지 않는다. 정보량을 늘리기보다 현재 콘텐츠의 순서와 높이를 다듬는다.

## 히어로

### 콘텐츠

- 영문 키커: `AI TAROT · SAJU`
- 제목: `지금의 마음을 / 별빛 아래 펼쳐보세요`
- 설명: 질문과 생년월일로 시작하는 조용한 리딩이며, 복잡한 마음을 천천히 바라보도록 해석한다는 의미를 짧게 전달한다.
- 기본 CTA: `타로로 시작`
- 보조 CTA: `사주로 시작`

### 배치

- 행성, 달, 궤도 및 별자리 형태의 독립 일러스트를 렌더링하지 않는다.
- 키커, 제목, 설명, CTA를 하나의 중앙 정렬 열에 배치한다.
- 설명의 최대 너비를 제한해 긴 한 줄이 되지 않게 한다.
- CTA 두 개는 데스크톱에서 가로로, 매우 좁은 모바일에서는 필요한 경우 줄바꿈할 수 있게 한다.
- 히어로 높이를 기존보다 줄여 다음 선택 카드가 데스크톱 첫 화면에 일부 또는 전부 나타나게 한다.

### 동작

- 두 CTA는 기존 타로·사주 진입 경로를 사용한다.
- 링크의 실제 목적지가 선택 카드와 동일해야 한다.
- 새 애니메이션이나 자동 재생 효과는 추가하지 않는다.

## 타로·사주 선택 카드

- 기존 두 카드 구조와 핵심 문구를 유지하되 세로 높이를 줄인다.
- 데스크톱에서는 2열, 모바일에서는 1열로 표시한다.
- 카드 전체를 클릭 가능한 진입 영역으로 유지한다.
- 카드 종류, 제목, 짧은 설명, 방향성을 보여주는 화살표의 위계를 명확히 한다.
- hover뿐 아니라 `focus-visible`에서도 동일한 수준의 강조를 제공한다.
- 애니메이션은 위치 이동이나 테두리·광택 변화 정도로 제한하고 `prefers-reduced-motion`을 존중한다.

## 신뢰 정보 스트립

선택 카드 아래에 다음 세 정보를 짧게 표시한다.

- Google 로그인 후 시작
- 완료한 리딩 기록 저장
- 선택을 돕는 성찰형 해석

이 영역은 과도한 배지 모음처럼 보이지 않도록 상하 구분선과 짧은 텍스트만 사용한다. 모바일에서는 자연스럽게 줄바꿈한다.

## 이용 방법

기존 3단계 설명을 유지한다.

1. 질문을 남긴다.
2. 카드 또는 사주 정보를 선택한다.
3. 나만의 해석을 읽고 기록한다.

데스크톱에서는 3열, 모바일에서는 세로 목록으로 표시한다. 긴 카드 UI 대신 얇은 골드 구분선과 숫자, 제목, 한 줄 설명으로 편집물 같은 리듬을 만든다.

## 반응형 기준

### 데스크톱

- 기준 시안은 1440px 너비를 우선한다.
- 콘텐츠 최대 너비는 기존 사이트 규칙을 따른다.
- 헤더 아래 히어로를 압축하고 선택 카드의 존재가 첫 화면에서 인지되게 한다.
- 히어로 카피는 화면 중앙에 오며 장식 그래픽이 차지하던 오른쪽 열은 제거한다.

### 모바일

- 기준 시안은 390px 너비를 우선한다.
- 히어로는 단일 열 중앙 정렬을 유지한다.
- 선택 카드는 세로로 쌓고 각 카드 높이를 과도하게 키우지 않는다.
- 신뢰 정보는 줄바꿈 가능해야 하며 가로 스크롤을 만들지 않는다.
- 주요 CTA는 44px 이상의 터치 영역을 확보한다.

## 접근성

- 본문 및 보조 문구는 실제 배경에서 WCAG AA 대비를 만족해야 한다.
- 링크와 버튼에는 키보드 `focus-visible` 표시를 제공한다.
- 카드 전체 링크의 접근 가능한 이름이 카드 목적을 명확히 설명해야 한다.
- 장식용 CSS 요소가 스크린 리더에 노출되지 않게 한다.
- 모션 감소 설정에서 불필요한 전환과 이동을 제거한다.
- 제목 구조는 페이지당 하나의 `h1`과 순차적인 하위 제목을 유지한다.

## 광고 확장성

이번 변경에는 광고를 표시하지 않는다. 향후 광고를 도입한다면 이용 방법 섹션 다음과 푸터 사이가 가장 자연스러운 인라인 후보 위치다.

이 위치는 핵심 CTA와 선택 카드 앞을 막지 않고, 사용자가 서비스 설명을 읽은 뒤 노출된다. 실제 도입 시에는 광고 라벨, 고정 높이 또는 레이아웃 이동 방지, 모바일 크기, 개인정보 및 동의 정책을 별도 설계한다.

## 구현 범위

주요 변경 대상은 다음으로 제한한다.

- `src/app/page.tsx`: 랜딩 콘텐츠 및 의미 구조
- `src/app/globals.css`: 랜딩 전용 레이아웃, 반응형, 상태 스타일
- 랜딩에서 사용하는 자체 호스팅 글꼴 파일과 라이선스 고지
- 랜딩 관련 테스트: 문구, 링크 목적지, 주요 구조 및 회귀 검증

공통 헤더와 푸터는 현재 구조가 새 랜딩과 충돌하는 경우에만 최소한의 스타일 조정을 허용하며, 기능과 다른 화면의 표현은 바꾸지 않는다.

## 검증 기준

- 랜딩 관련 테스트가 통과한다.
- 타입 검사, 린트, 프로덕션 빌드가 통과한다.
- 1440px 데스크톱과 390px 모바일에서 육안 검증한다.
- 두 화면에서 가로 오버플로가 없다.
- 타로·사주 CTA와 선택 카드가 올바른 기존 경로로 이동한다.
- 키보드 탐색 순서와 `focus-visible` 상태를 확인한다.
- 마루부리와 Pretendard가 네트워크 런타임 요청 없이 실제로 적용되는지 확인한다.
- 웹폰트 전후 레이아웃 이동과 제목 줄바꿈이 허용 범위인지 확인한다.
- 브라우저 콘솔에 새 warning 또는 error가 없다.
- 마일스톤 완료 시 저장소 규칙에 따른 전체 검증을 한 번 실행한다.
