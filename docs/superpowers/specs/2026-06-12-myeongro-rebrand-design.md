# 명로 서비스 리브랜딩 설계

## 목표

임시 서비스명 `운담`과 영문 식별자 `WOONDAM`을 공식 서비스명 `명로`와
`MYEONGRO`로 전면 교체한다.

## 범위

- 사용자 화면, 메타데이터, 접근성 라벨, README의 브랜드명을 `명로`로 변경한다.
- 패키지 이름을 `myeongro`로 변경한다.
- 신규 게스트 쿠키 이름을 `myeongro_guest`로 변경한다.
- 기존 `woondam_guest` 쿠키는 서명을 검증한 뒤 동일 토큰을 새 쿠키로 이전하고
  구 쿠키를 만료한다.
- 과거 `woondam_*` localStorage 키는 기존 브라우저 데이터 정리를 위해 삭제
  코드에만 남긴다.
- 일반적인 기능 설명인 `fortune reading`과 과거 계획 문서 제목은 브랜드
  오표기가 아니므로 문맥에 맞는 경우 유지한다.

## 호환성

신규 쿠키를 우선 사용한다. 신규 쿠키가 없고 유효한 구 쿠키가 있으면 해당
게스트 세션 ID와 만료 시각을 그대로 유지해 `myeongro_guest`를 발급하고
`woondam_guest`를 즉시 만료한다. OAuth 소유권 이전 성공 시 두 쿠키를 모두
만료한다.

## 검증

- 구 쿠키가 동의 API와 무료 리딩 API에서 동일 게스트 소유자로 인식되는지 확인한다.
- 구 쿠키 사용 응답이 신규 쿠키 발급과 구 쿠키 만료를 함께 포함하는지 확인한다.
- 화면과 저장소에서 의도하지 않은 `운담`, `WOONDAM`, `woondam` 표기가 남지
  않았는지 정적 검색한다.
- 전체 테스트, 타입 검사, 린트, 프로덕션 빌드를 실행한다.
